# Page Topology

1. **Minimal top bar** — brand and quiet status only.
2. **Wheel screen** — centered title, subtitle and a single large SVG wheel.
3. **Items tab** — floating left-side tab showing live count; opens the editor drawer.
4. **Items drawer** — add form, individual remove buttons, mix, clear and conclude actions.
5. **Wheel controls** — sound toggle, spin button, fullscreen button and accessible live result.

The page uses document scrolling only. Drawer is a fixed overlay. The only time-driven interaction is the wheel spin.
